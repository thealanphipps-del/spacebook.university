## 🏛️ Executive Statement & Context

Under **Constitutional Draft v1** (RFC-0025 through RFC-0030) and the **SPU Phase I Empirical Framework** (SPU-0007, Baseline Epoch 73), Spacebook transitions from an abstract distributed coordination protocol into physical human and edge reality.

The **Spacebook Mobile Application** ("Predator Edge Node") is not a traditional passive client or social media wrapper. It is a **first-class sovereign node** in the distributed computing topology. Each participant device acts as:
1. A **hardware-isolated key enclave** for cryptographic identity and non-custodial $ATTN$ settlement.
2. An **active attention sensor** measuring intentional human cognitive engagement and minting causal contribution lineages ($gATTN$, $rATTN$).
3. A **sovereign consent enforcement gate** partitioning personal telemetry into Green, Yellow, and Red zones via local differential privacy.
4. A **distributed neural execution unit (Edge NPU)** executing verifiable local inference cycles, contributing to the decentralized intelligence substrate.

### Section 1: Core Android Architecture & Lifecycles

```
┌────────────────────────────────────────────────────────┐
│             Jetpack Compose UI Layer (MVI)             │
│  Consent Matrix | Attention Meter | Mesh Peer Graph    │
└──────────────────────────┬─────────────────────────────┘
                           │ StateFlow / Coroutines
┌──────────────────────────▼─────────────────────────────┐
│          KMP Core Domain & State Machine               │
│  Consent Engine | Attention Protocol | Mesh Sync Core  │
└───────┬──────────────────┬──────────────────────┬──────┘
        │                  │                      │
┌───────▼────────┐ ┌───────▼───────────┐ ┌────────▼──────┐
│  StrongBox     │ │ Foreground Edge   │ │  SQLCipher    │
│  Keystore Enclave│ │ Service (0x7300)  │ │  Local DB     │
│  ECDSA / Ed25519│ │ Duty-Cycle Loop   │ │  Offline SSOT │
└────────────────┘ └───────────────────┘ └───────────────┘
```

1. **Language & Multiplatform Strategy:**
   - **Language:** Kotlin 2.0+ with modern language idioms.
   - **Architecture:** Kotlin Multiplatform (KMP) architecture:
     - `commonMain`: Consent Matrix state machines, attention scoring algorithms, serialization, cryptographic proof verifiers.
     - `androidMain`: Android Keystore integration, StrongBox bindings, CameraX/Biometrics, WorkManager, and NPU JNI bindings.
   - **UI Framework:** 100% Jetpack Compose (Modern Material 3, Dark-mode first, zero legacy XML fragments).

2. **Persistent Background Execution Engine:**
   - **`SpacebookEdgeNodeService` (Foreground Service):**
     - Type: `FOREGROUND_SERVICE_TYPE_DATA_SYNC | FOREGROUND_SERVICE_TYPE_CONNECTED_DEVICE`.
     - Non-killable notification displaying real-time edge telemetry (Peers Connected, Tokens/Watt, Consent Zone).
     - Controlled `PartialWakeLock` governed strictly by battery and thermal state.
   - **`WorkManager` Schedulers (Periodic Deferrals):**
     - `ConsentAuditWorker`: 24-hour differential privacy parameter drift verification.
     - `TelemetryBatchWorker`: Off-peak cryptographic batch settlement when device is charging and on unmetered Wi-Fi.

3. **Cryptographic Key Enclave & Hot Wallet Isolation:**
   - **StrongBox Keystore (API $\ge 31$):**
     - `attnHotWalletKey`: ECDSA P-256 / secp256k1 key generated inside the Secure Element. Export prohibited (`setPurposes(PURPOSE_SIGN)`).
     - `meshIdentityKey`: Ed25519 peer ID key for libp2p cryptographic peer addressing.
     - `storageEncryptionKey`: AES-256-GCM hardware key for SQLCipher database encryption.
   - **Biometric Integration:** High-assurance transactions ($ATTN$ transfer, consent policy modification) require hardware biometric confirmation via `BiometricPrompt.CryptoObject`.

### Section 2: Edge AI & NPU Runtime Specification

```
                      Inference Request
                             │
            ┌────────────────┴────────────────┐
            │  Dynamic Thermal/Power Router   │
            └────────────────┬────────────────┘
                             │
     ┌───────────────────────┼───────────────────────┐
     ▼                       ▼                       ▼
┌──────────────┐    ┌─────────────────┐    ┌──────────────────┐
│ NNAPI / QNN  │    │ ONNX Runtime    │    │ ggml / llama.cpp │
│ Micro-Models │    │ Vision / Audio  │    │ 4-bit LLM Engine │
│ Latency ≤15ms│    │ Latency ≤30ms   │    │ Latency ≤80ms/tok│
└──────────────┘    └─────────────────┘    └──────────────────┘
```

1. **Multi-Backend Neural Engine:**
   - **NNAPI / Qualcomm QNN / MediaTek NeuroPilot:** Direct hardware acceleration for sub-20ms deterministic models.
   - **ONNX Runtime GenAI Mobile (`onnxruntime-android`):** Cross-platform fallback for complex neural graphs and vision encodings.
   - **`llama.cpp` JNI Core (`libllama.so`):** Native C++ mobile bridge supporting quantized GGUF weights (`Q4_K_M`, `IQ3_XXS`) for local context classification and semantic grounding.

2. **On-Device Model Catalog:**
   - `spacebook-attention-v1`: 25MB quantized encoder evaluating active user reading/viewing cadence, gaze intent, and scroll coherence ($\le 25\text{ ms}$).
   - `spacebook-consent-filter`: 8MB localized classifier flagging accidental PII ingress before any data leaves memory ($\le 10\text{ ms}$).
   - `proof-of-presence-net`: 4MB acoustic and spatial sensor fusion network proving physical proximity without location tracking ($\le 15\text{ ms}$).

3. **Thermal & Battery Protection Governor:**
   - Dynamic monitoring via `PowerManager.addThermalStatusListener`:
     - `THERMAL_STATUS_NONE`: Full throughput (up to 20 inference cycles/min).
     - `THERMAL_STATUS_MODERATE`: Throttle throughput by 40%, reduce context window.
     - `THERMAL_STATUS_SEVERE`: Suspend background neural inference; maintain basic mesh heartbeat only.
   - Battery Governor: When disconnected from power and battery level $< 20\%$, edge computing is paused automatically to preserve user phone lifeforce.

### Section 3: Mesh Networking & Sovereign Protocol Stack

1. **Transport Layer:**
   - **QUIC Multiplexing:** Primary transport protocol over cellular/Wi-Fi via embedded `quic-go` / `cronet` engine. Zero-RTT connection resumption and resilience against mobile IP handover.
   - **Tailscale WireGuard Mesh Integration:** Embeds `tailscale-android-sdk` to establish peer-to-peer tunnels directly to Lion baremetal (`162.244.82.31`) and Apex1 cluster (`100.97.133.107`) without public relay exposure.
   - **Bluetooth Low Energy (BLE) Ad-Hoc Mesh:** Local proximity discovery and offline peer-to-peer state propagation via BLE advertisements when internet connectivity is severed.

2. **Local Data Persistence (SQLCipher / Room):**
   - 100% encrypted on-device database storing:
     - `consent_policies`: User-defined Green/Yellow/Red zone rules.
     - `attention_receipts`: Locally verified attestation merkle trees.
     - `peer_routing_table`: Verified reachable mesh nodes.
     - `empirical_snapshots`: Periodic local measurements staged for observatory sync.

### Section 4: Privacy, Sovereign Consent & Tokenized Settlement

1. **Granular Consent Matrix (Mobile Implementation):**
   - **Green Zone (Public Substrate):** Knowledge contributions, RFC peer reviews, verified node uptime, public research annotations. Telemetry is cryptographically signed and broadcast.
   - **Yellow Zone (Differential Privacy):** Aggregated attention metrics, hardware performance profiles. Processed strictly through local DP-SGD before submitting noise-injected gradients to cluster.
   - **Red Zone (Sovereign Enclave):** Raw keystrokes, personal communications, unencrypted locations, device telemetry. Strictly forbidden from leaving the device. Zero network sockets open.

2. **Attention Tracking & Settlement:**
   - Attention events generate non-fungible attention claims ($AC$) hashed via BLAKE3.
   - Batched claims submit to `POST /api/v1/settlement/clear` on cluster nodes, issuing $gATTN$ and $rATTN$ into the participant's StrongBox-backed address.
